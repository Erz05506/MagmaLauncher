MagmaLauncher Alpha 1
Неофициальный лаунчер Minecraft: Java Edition. Vanilla, Fabric, Forge, NeoForge, Quilt. Написан на C++ (CEF) и JavaScript.
Лаунчер сам качает нужную версию Java, ассеты и загрузчики, ставит Fabric/Forge/NeoForge/Quilt в пару кликов и умеет собирать модпаки из каталогов Modrinth и CurseForge — без ручной возни с файлами.
Код распространяется по лицензии MIT — использовать, менять и форкать можно свободно.
